Don't trust this page. Check the log.

Every draw a Vela device authorises is anchored on Hedera with a 29-byte statement the chip signed: slot, sequence, payee, amount, and the balance left. This page reads those statements straight from Hedera's public mirror node and checks them in your browser.

No Vela server is involved. Open the network tab — the only origin this page talks to is testnet.mirrornode.hedera.com.

Topic id

reads Hedera. Writes nothing, anywhere.

What this proves, and what it does not

Proves

  • every anchored draw settled on Hedera exactly as recorded
  • in order, with no sequence hidden
  • against one fixed envelope
  • and never past its ceiling
  • each statement signed by the key that owns the paying account

Does not prove

  • that the service delivered anything
  • that the envelope was a sensible size
  • that the agent did anything useful
  • that a host published every draw it made — a host that anchors nothing proves nothing, which was always true
The agent holds no key. The host holds no key. github.com/edenbd1/vela
